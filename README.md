# UNITY Kitty Jump

## Description

A simple game which I made for my portfolio

Kitty Jump is the recreation of "Doodle Jump". Made on Unity

In this Project i've learnt next:
* How to implement basic Character controls
* How to implement random Object generation with random position using Prefabs
* How to work with RigidBody2D component
* How to change and reload Scenes
* How to implement interactable UI elements
* How to implement Save/Load system

### CONTROLS:
A/D - Left/Right

### Play for free on [itch.io](https://bert-gotraxx.itch.io/kitty-jump)
